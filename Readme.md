# 🐍 Snake Game

A classic Snake Game built in Python using the Turtle graphics library. Control the snake, eat food to grow longer, and avoid colliding with the walls or your own body.

---

## 🎮 Features

- Smooth snake movement
- Random food generation
- Score tracking
- High score persistence
- Collision detection
- Game over and restart functionality
- Simple and clean UI

---

## 🛠️ Technologies Used

- Python 3
- Turtle Graphics
- Object-Oriented Programming (OOP)

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/harshvec/Snake-Game.git
```

2. Navigate to the project folder

```bash
cd Snake-Game
```

3. Run the game

```bash
python main.py
```
